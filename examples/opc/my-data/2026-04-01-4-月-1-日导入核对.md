# 4 月 1 日导入核对

今天没有继续加来源，只看已经进入受限试点的副本。陈放的“是不是删了”先记作用户看到的现象，不记作删除事件。我给吴岚的回复只有两点：条目在来源侧还能定位；项目页日期有偏移，原因和修复时间都没有结论。她回“先别让大家补录”，这条边界维持不变。

消息重复另开一页记。我抽的两对内容相同，但一对 message id 相同、线程位置不同，另一对 id 不同、正文相同。前一种可能是展示展开，后一种也可能来自同步或编辑历史；现在没有足够样本把它们归成一类。今晚只保存对照 id 和出现位置，没有合并或删除任何副本。

- [x] 留下录制来源时间与项目页分组截图
- [x] 回答陈放：来源记录还在，页面日期不对
- [ ] 确认全部录制是否同样跨日
- [ ] 回放历史批次
- [ ] 打开邮件附件索引并核对对象可用性
- [ ] 检查名称候选是否可靠

傍晚洗衣机脱水时晃得撞墙，我和赵楠把它往外挪了半寸，又垫回一块旧毛巾。收床单时右肩抬不高，赵楠问还开不开上周那局，我说今天不玩。他自己戴耳机进了游戏，我煮了速冻馄饨，漏勺滑进锅里，汤溅了一圈；擦完灶台就去洗澡了。

睡前把显示修复、历史回放和附件索引分成三栏。第一栏今天没有动；第二栏只选了样本，还没运行；第三栏甚至没打开。明天如果仍想先处理最显眼的页面问题，至少要在记录里写清它不会回答数据层是否正确。

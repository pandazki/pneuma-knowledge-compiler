# 下一次只问动作

开场别展示原型。请对方挑最近一次被追问改动的时刻，从桌面还没打开任何窗口开始讲。若他说“我就搜了一下”，继续问他记得的第一个词是什么、搜空以后换了什么，不问他想要哪个功能。

- 第一个想到的是人、日期、房间，还是某句含混的话？
- 哪个窗口开了又关？为什么？
- 中途向谁求助？对方给的是位置还是解释？
- 最后停下时，手里多了什么，仍缺什么？

待吴岚确认：她只说会先问协调人，不代表对方愿意。问题清单现在留在本地。若下次仍是吴岚自己讲，也把它当第二个样本，不把今天的路径写成团队习惯。

空卡三张：材料、费用、交付日期。卡上只放“起点 / 转向 / 停下”，不填结论。今天 A 有口述过程，B 与 C 只有题目；空着比从常识补全可靠。

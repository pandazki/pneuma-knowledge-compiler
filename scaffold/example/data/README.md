# 演示数据（可整目录替换）

这是一套**纯合成**的快速体验数据：独立开发者陈晚在两周里推进个人项目
aurora-planner（一个本地优先的周计划工具）的笔记与对话，涉及协作者林知远
（维护同步引擎 Atlas）与设计师宋遥。

- 每个文件 = 一份材料（一次对话 / 一篇笔记），frontmatter 的 `date` 是该对话或笔记的
  记录日期。文中提到的过去事件、计划和里程碑使用各自的时间，不能都记在材料日期上。
- 跑通 demo 之后，把这个目录整个换成你自己的样本，或用
  `./app.py ingest <你的目录>` 指向别处。
- 本文件（README.md）不会被摄入。

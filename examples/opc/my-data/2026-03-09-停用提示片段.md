# 停用提示片段

这页只收今天从运行分支剪下的旧提示，方便看差异；它们不会再参与演示。输入一直是角色甲乙和编造短句，没有放入陈放的消息，也没有等待中的旧材料。保留这页不等于保留产品方向。

```text
片段 A
输入：按日期排列的几条虚构短句
旧动作：补成“本周发生了什么”，缺少原因时从相邻句猜。

片段 B
输入：一句话和两个角色称呼
旧动作：推测为什么改变、谁负责，以及接下来会怎样。

片段 C
输入：只有摘要，没有可返回的位置
旧动作：继续生成一张看起来完整的卡片。
```

10:36 用三条临时句各跑一次。A 把两个未回答的问题写成了肯定原因；B 给角色乙补了并不存在的职责；C 隐藏了位置为空。输出看起来比输入整齐，却多出输入里没有的关系，所以没有把生成结果保存成展示样例。

| 旧片段 | 本次处理 | 运行分支现在剩什么 |
| --- | --- | --- |
| A | 整段移除 | 日期与原样短句 |
| B | 整段移除 | 两个角色称呼，各自不补职责 |
| C | 整段移除 | 明示位置为空，按钮仍无目的地 |

删改只解决“不要凭空补齐”，没有解决卡片从哪里取原句，也没有证明三种来源能用同一种定位。旧提示复制在本页是为了核对删除范围，不是下一版需求；若以后重开，必须重新写测试，而不是把这三段粘回去。

11:18 手工检查窄屏。长句在第二行被截断，空位置仍占一行，两个角色名不会再自动并成一个。用键盘顺序走过三张卡时，焦点会停在没有目的地的按钮上；按下去只回到页首。第二张卡的日期被截短后看起来与第一张同日，我没有加悬浮说明遮过去。颜色和排序没有动，首页概览也还在另一个折叠区。今天只确认删改没有让页面崩掉，不判断陈放会不会因此采用。

收尾时把运行分支、停用片段和当天截图放进三个不同目录。截图中只有虚构文字；停用页不对外共享。关闭分支后不再接收剪贴板内容，输入目录仍为空。

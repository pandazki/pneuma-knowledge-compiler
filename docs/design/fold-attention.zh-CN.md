# 个人版中的 Fold 注意力复盘

[English](fold-attention.md) | **简体中文**

状态：实验性集成。Fold skill 仅经过初步判断评估，没有生产质量保证。本功能是个人版独立消费链路，
不改变摄取、编译、闸门、正本串行通道或派生重建行为。

## 用途

知识库天然滞后；看板服务于长链条复盘和未来规划。顶层是持续项目或主题，具体事件通常作为支撑细节，
只有特别重要的事件单独浮现。带依据的复盘连接阶段意义、方向变化、跨项目张力以及下一阶段的问题。
观察与推断分开：有规划的 pivot 必须有目标或理由记录；沉默不证明停滞或个人缺点。
上一轮复盘及其来源进入下一轮上下文。原有细碎事项可以重新组织为宏观主题，不声称旧任务已完成。

## 边界与执行

每个个人版引擎监督独立的 `pkc_personal.attention.worker` 进程；库内文件锁保证一个注意力进程。
通过 `git --no-optional-locks` 读取已提交对象，不读工作树，只写 `<library>/attention/attention.sqlite3`。
另开 PostgreSQL 连接，通过时间投影读取 L0 中带日期的 Owner 发言；数据库强制只读事务，语句超时 15 秒，
所有查询与连接都限定当前库的租户。项目身份读取完整的采集观察记录，不获取采集写锁。
模型失败、退避和轮询独立于知识任务队列。引擎退出会取消旁路及其执行器；父进程监视处理异常退出。
机器资源和服务商额度仍然共享，独立不意味着零资源竞争。

使用知识库选定的 Codex/Claude Code 后端或 API recall 模型。编码代理在临时目录运行，不携带 Steward skill。
Codex 开启只读沙箱，禁用 shell、unified exec、JavaScript、apps、multi-agent、网页搜索，忽略用户配置和规则。
Claude 使用空工具集、严格空 MCP 和空本地配置来源。没有编译执行器、`pkc draft`、正本写方法或行动工具。
调用限时 180 秒，校验最多修复两次；CLI 不支持这些参数时失败关闭。

用户身份由服务引擎绑定，不能在请求中选择其他租户。控制台仅为该引擎画像嵌入看板。
路由拒绝非本机 Host 和跨源写请求；托盘仅嵌入本机页面，不授予 Tauri 能力。

## 触发与保留记录

默认启用：固定合并窗口 300 秒、五个知识版本触发、最短调用间隔 300 秒、六小时安静复盘。
持续输入不会推迟窗口起点；手动复盘与批注也遵守最短间隔。没有待消费知识时才产生空事件，明确外部覆盖未知。
持久化观察游标与待处理文档集合分开，重启保留。接受时只消费本轮捕获的版本，新提交下轮观察。
首次启动优先最近变化；每轮最多 16 篇正本文档，携带提交时间，但不把它当事件发生时间。
模型节选最多每篇 16,000 字符并标记截断，原始供应文档作为证据保存，剩余文档继续等待。
只读正本 Markdown，排除 archive/ 与契约文件；Git 历史重写后重新观察现行文档集合。
独立的日期视图覆盖编程会话 Owner 发言，包括尚未编译的材料；其他渠道仍为未知。

回看默认 14 天，可设为 7 至 90 天。按原始来源日期定位，绝不使用入库或编译日期。
按原生 turn ID 去重增量导出。数量表示记录中的参与，不是工时；零值表示无匹配观察。
最多读 20,000 条发言并声明截断。前十项目按日取首尾发言，再均匀抽取最多 96 个样本，每条最多 1,200 字符，
引用精确来源块；完整逐日聚合另外提供。时间投影或数据库不可用时显示覆盖不可用，不编造河流。

固定版本 Fold 内核校验预算、身份、操作、补丁、批注和重试。新事项必须引用供应的正本或 L0 ref；
新增引用必须来自当前包或既有准入来源。这验证溯源，不证明语义蕴含。
沉默不会机械降权；判断可依据时间信号降低、维持或提高份额。无变化复核也保存一帧，不制造事项更新。

SQLite 事务原子保存 Fold 快照、触发信号、收据、证据、HEAD、复盘、日期视图和指引 SHA-256。
复盘块必须有非空文字和至少一个已供应或既有准入引用。历史帧是实际判断的追加保留记录，不是知识权威，
也不由 `rebuild_derived` 重建；保留当时的时间投影。generation 乐观校验防止迟到模型响应覆盖 Owner 批注。
失败保留上一轮与待处理材料，五分钟至六小时指数退避；UI 不展示失败的服务商原始输出。

## 界面

引擎在 `/home/attention/view` 提供一套实现，由 920 点宽托盘（看板视口 650px）和控制台嵌入，按库共享设置。
初始视图为主题版图，河流是可选角度，不是指定的最佳首页。控件与日期后直接呈现图形；
带引用的复盘只在图下出现一次，不放开场口号或重复的设计理念。

- **时间河流**：所选时段按原始日期呈现项目参与、稳定项目颜色、观察缺口和每周总量；回溯的是活动记录，不是历史判断。
- **空间版图**：项目/主题按份额占据面积，并保留真实留白；可以展开细节与子主题，顶层不变成任务列表。
- **流动形态**：直接使用 Fold C 的 WebGL2 液滴着色器与布局求解器，支持 Canvas2D 回退、有界过渡和减少动画偏好；细小主题沉为珠点。
- **轮次方阵**：实际保存的每轮复盘都用同尺度 64 格表达。
- **主题脉络**：追踪稳定身份、改名和份额变化，仅对明确记录的合并画连接。
- **份额让位**：比较相邻复盘中的释放与获得，包含留白，两侧守恒、统一尺度，不虚构谁为谁让位的因果配对。

主题可查看理由、固定证据、支撑细节和 Owner 批注。复盘段落链接到保存的依据。
批注只进入 Fold 反馈，不执行任务、不隐式写入正本。来源样本可能是节选，证据按当时供应内容保存。

底部固定时光机支持前后、拖动、播放、加载更早记录和回到现在。旧帧只读保留当时的解释与日期视图，
不编造启用之前的注意力历史；独立于控制台正本快照选择器。设置提供六种形式、回看时段、合并窗口、
最短间隔和安静复核；新回看范围在下一轮生效。关闭自动复盘保留历史，仍可手动请求。
浏览不会调用模型，也不会被当作已读事项。

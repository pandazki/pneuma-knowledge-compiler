# 控制台的口袋仪表

[English](DESIGN.md) | **简体中文**

知识库的 Owner 坐在阅读桌前，在日光或台灯下瞥一眼 Mac 菜单栏。托盘属于控制台的校样世界：暖纸、墨色、细线、脚注。它安静、书卷气、精确。已确认的背景在 [.impeccable.md](.impeccable.md)，控制台自己的设计文档（世界观与色板）提供参考。实现与设计令牌均保存在此处，不导入控制台代码。

## 表面与令牌

`src/styles.css` 定义原生外壳的所有颜色；引擎提供的 Fold 嵌入页在下文另述。`color-scheme: light dark` 与 `light-dark()` 跟随系统外观。Paper 与 Lightbox 分别调校。中性色统一使用色相 85，次要文字的明度经过调整以保持可读。蓝铅笔和健康色由控制台的 sRGB 数值转换而来。健康色只用于库名旁的小圆点；原生托盘图标保留既有契约。打开控制台时，这张面孔以 `?locale=` 与 `?theme=` 一并交出，主题取自 `light-dark()` 所依据的同一条 `prefers-color-scheme` 查询，浏览器不必再去猜一个用户早已选定的语言。错误与失败详情以普通表面上的文字表达。

## 字体与读数语法

- 衬线：`"Alegreya", "Songti SC", "Noto Serif CJK SC", serif`。用于标题、斜体页眉和读数。
- 无衬线：`"Alegreya Sans", "PingFang SC", "Hiragino Sans GB", "Noto Sans CJK SC", sans-serif`。用于界面、回答和来源行。两个字族不互为回退。
- 固定 rem 字阶：相当于 11 / 13 / 15 / 20 / 28px。15→20→28 的主层级比率大于 1.25；11 与 13 分别用于辅助脚注和元信息。中文元信息用 13，不用 11。CJK 的相应行高增加 0.1，字距为零。中英混排标题保留完整无障碍名称，视觉上最多两行。
- 拉丁标签使用 `all-small-caps`，字距 `0.04em`；中文标签不变形。数字使用 `tabular-nums lining-nums`。
- 随仓库提供的 Latin WOFF2：`alegreya-{normal,italic}-latin.woff2`（可变字重 400–900）；`alegreya-sans-{300,400,500,700}-normal-latin.woff2` 与 `alegreya-sans-400-italic-latin.woff2`（静态字重）。提供的 Sans 字族使用真实静态字重。每个字体均声明 `font-display: block` 和拉丁 `unicode-range`，预加载首次打开所需的四个字体文件，运行时不从外网获取字体。SIL Open Font License 1.1 全文在同目录的 `OFL-Alegreya.txt` 和 `OFL-Alegreya-Sans.txt` 中，并链接到构建产物。

读数为 `标签 ………… 数值`，使用定义列表和装饰性点状引导线。顺序固定为引擎、队列、最近编译、同步、密钥、skill 包。队列成功（`queue.succeeded`）、待处理与失败分别呈现，失败种类置于下方的 ink-3 文字中。同步暂存增量不冒充队列数量。未知或不完整的读数只显示一个 `—`，不拼接单位或状态词；已知零值与已观测到的尚无历史工作仍有明确含义。当前库排在最前；深层观测不得借用其他引擎的响应。Skill 的中文名称为 `skill 包`；未手动选择时，语言继续跟随系统。

## 控件语法

设置沿用 `标签 ………… 控件`，数值用墨色，并声明 `appearance: none`。选择框收起时没有方框，CSS 用 1px 线条绘制小下箭头；展开时保留 macOS 原生弹出列表。悬停时整行叠加控制台的悬停墨色；聚焦时在数值下方绘制 1px 强调色细线。同步间隔是裸露的等宽数字，后接单位，配以无底色的 −/+ 文字按钮和既有保存操作。开关同时显示开/关两词，选中词为 ink，非选中词为 ink-3，中间用 1px 细线分隔；保留开关语义及设置项名称。密码与文字输入框只有底部细线，没有方框或填色，密钥仍使用真正的 password 输入框。搜索同样没有方框或填色：聚焦仅由整个页眉底部的 1px 强调色细线和光标表达，占位提示用 ink-3 与 Alegreya Sans。

## 布局与交互

面板初始为 920×820；内容适配随后将高度限制在 280–820 点之间。顶部固定 44px 无边框搜索行，包含放大镜、本地化提示和 ⌘K，下方内容区可滚动。内容垂直留白 16px、水平留白 20px，读数行高 32px，区块以 24px 留白与细线分隔。内容区声明 `min-height: 0` 并按内容收缩：内容较短时，本机分隔线、健康行和页脚紧接其后。内容超过可用高度时（包括两个知识库），只有内容区滚动，搜索与页脚保持固定。停止的服务前加点。五个配置步骤保持顺序和间隔号：已完成词为 ink，未完成词为 ink-3 并带 1px 点状下划线，第一个未完成词带强调色细线。

输入后经过短暂防抖显示结果；中文输入法组词完成后才发出搜索。回答为纯文本，引用为上标编号脚注，后接来源条目。⌘K 聚焦搜索；Escape 先清空查询，再关闭面板。上下键移动引用链接焦点；Enter 打开当前引用，在搜索框内则打开第一条引用。控件使用上述焦点细线，其他按钮与链接保留 2px 蓝色焦点环和 2px 偏移。

设置通过页脚文字链接进入，采用上述控件语法。移除目录在悬停或键盘聚焦时显示。已保存的嵌入密钥是一条读数，而非常驻的填写框：显示凭据名称、保存时间，以及已被证实的状态——引擎已验证（启动为 fail-closed，语义检索开启时引擎在启动时用该密钥探测服务商，故运行中的引擎即是服务商的判定）、引擎未运行时为尚未验证、语义检索关闭时为未使用。「替换」展开名称与密钥输入，「取消」收起，保存成功后同样收起。状态未知时只显示一个 `—`。密钥框从不明文展示，提交即清空，面板关闭即卸载；凭据被拒绝时如实说明服务商给出的原因，提交值的每一次出现都在离开 Rust 侧之前被替换为 `•••`。无人值守编译说明关闭后的后果。「登录时启动」自首次启动即开启——托盘就是这一版的同步，重启后不再回来的托盘，等于一座悄悄停止倾听的知识库——开关下方的说明把这一点直说；应用只决定一次并记录下来，Owner 此后的选择是最终的，不会被应用重新替他决定；系统拒绝注册时，开关显示为关闭，并在同一行说明系统给出的原因，而不是伪装成一次无人给出的成功。操作均为无底色文字按钮；只有引擎停止时的启动操作使用主强调色。启动、停止与重启依然作用于整个 home。

页脚显示检查时间或渐隐的单行状态，旁边为设置和退出。打开面板使用缓存状态与既有 `setTimeout` 显示握手。内容只在打开时用透明度和向上 2px 位移，在 120ms 内就位，曲线为 `cubic-bezier(0.22, 1, 0.36, 1)`；实时更新不闪烁。减少动态效果偏好禁用动画。尚未配置时显示短段落和可粘贴给编程代理的一句话；引擎停止或 Docker 故障时仍保留已知读数。

禁止：卡片与卡片网格、标签页栏、标题上方图标、居中大数字、侧边色条、渐变文字、辉光、装饰性玻璃效果、弹跳、紫色/青色色板、运行时字体服务，以及编造健康状态或来源的呈现。

存在等待重试或已暂停任务时，队列读数下方直接显示数量、本地时区的下次重试日期时间和「立即继续（N）」。说明将操作与额度、登录或网络恢复关联。内容操作改称「导入新内容」，说明会扫描监看目录；「重启服务」明确保留重试时间。成功反馈报告实际恢复数量，失败沿用现有消息行。


## 注意力扩展

Fold 为这件仪表增加长线阅读界面。上文原生外壳的身份与禁令继续有效。Owner 授权的例外仅限
引擎提供的 Fold 嵌入页：允许柔和的身份色、原版 Fold C 带光照的 WebGL 液滴，以及六选一的
视图预览设置区。这不授权原生外壳采用卡片或替换色板。产品背景见
[PRODUCT.zh-CN.md](PRODUCT.zh-CN.md)，行为与证据边界以
[Fold 设计文档](../../docs/design/fold-attention.zh-CN.md)为准。

### 布局与阅读顺序

原生面板宽 920 点，初始高 820 点，按内容在 280–820 点间适配。Fold 首屏使用 650px 高的可滚动
iframe；原生设置中的独立嵌入页高 680px。知识库健康位于其后的展开区域，引擎停止时默认展开。
控制台嵌入同一引擎界面，两个应用不互相导入源码。本机嵌入许可不会授予原生能力。

看板直接从视图控件、实际日期与视觉区域开始。带引用的阶段解读只在下方复盘中出现一次，
并提供证据与支撑线索。保留事实标签、视觉编码说明、实际数量与状态以及必要的操作帮助；
不添加口号、开场宣言、复制的设计讨论或重复摘要。空间版图是初始偏好，六种形式仍均可选择，
并按库共享。默认值不表示版图普遍最优，也不把河流作为产品中心。
根主题描述持续的项目、目标和问题，具体事件为其提供支撑。选择主题可查看理由、固定证据与
备注；可下钻子主题并返回宏观视图。历史复盘保持只读。

嵌入页采用最大宽 1400px 的流式单栏，两侧留白 24px；宽度超过 1100px 时为 38px。宽度不超过
600px 时改为 16px，复盘札记改为单栏，视图预览由三列变为两列。宽图表在自身区域内横向滚动。
桌面宽度、视口高度不超过 750px 时，页眉和控件间距压缩以保留视觉主体。已保存复盘的时光机固定于
嵌入页底部，正文预留底部空间，阅读与设置过程中都可操作。它支持逐轮切换、拖动、播放、加载
更早的记录和返回现在。它与河流的来源日期轴、控制台的 canonical 快照选择器各自独立。
不会虚构看板启用前的复盘历史。

承载。版图区域把身份色与纸色混合（25%，悬停时 35%），留白区域始终明确表示未分配空间。

正文字体为 15px/1.6 的 `"Alegreya Sans", "PingFang SC", "Hiragino Sans GB", system-ui,
sans-serif`。阅读区标题使用字重 500 的 `"Alegreya", "Songti SC", Georgia, serif`，

尺寸计算字号（13、15、17 或 21px）与最大行数。紧凑区域省略重复的份额元信息，完整标题和份额
保留在无障碍标签中。复盘段落为 14px/1.9；辅助控件与说明通常为 11–14px。它们使用本机字体回退，不继承或下载外壳的字体。外壳随包字体和无框控件
规则保持不变。

### 六种形式及其含义

| 形式 | 视觉契约 |
|---|---|
| 时间河流（`river`） | 项目色带使用来源原始日期与阶段合计。单行色键图例标识项目，不绘制引导连线；移动端将图例置于图表下方。数量表示被记录的参与，不表示工时。缺失观测保留为空缺，覆盖不可用时明确说明。 |
| 空间版图（`space`） | 按比例划分主题面积，使用有限的 64 份预算并包含真实留白。稳定的布局过渡保留方位感；选择区域查看详情和子主题。 |
| 流动形态（`drops`） | 原版 Fold C WebGL2 着色器与布局求解器按比例呈现主题，较安静的主题成为小珠。提供有界几何插值、Canvas2D 回退与减少动态效果处理。 |
| 轮次方阵（`mosaic`） | 每个 8×8 方阵代表一轮实际保存的复盘，统一为 64 份尺度，标注记录日期与时间。选择方阵进入那一轮。 |
| 主题脉络（`lineage`） | 稳定主题身份贯穿保存的轮次，宽度表示份额，节点表示变化，空缺表示未出现在看板中。斜向连接仅来自明确记录的合并。 |
| 份额让位（`yield`） | 相邻轮次在统一尺度上呈现守恒的让出与获得，包含留白。不暗示某个让出方与某个获得方之间的因果配对。 |

### 控件、纵深与动态

紧凑按钮和选择框使用细边框、3px 圆角，最小高 34px；文本输入框为 2px 圆角。焦点使用 2px
强调色轮廓，偏移 3px。视图预览为单选组，六项均包含示意图、名称和说明；选中项使用强调色边缘
与浅染底色。设置和形式选择按库保存，托盘与控制台共享；回看范围的修改在下一轮复盘生效。

纵深主要依靠纸色、细线和留白。固定时光机带柔和的纸色边缘阴影。带光照的液滴和小珠的内侧高光
属于限定的材质例外。减少动态效果偏好禁用 CSS 过渡、动画及视觉插值。证据与解释标签不依赖动态
或颜色即可访问。界面记录复盘与 Owner 留给下一轮的背景，不成为即时行动收件箱，也不把缺失观测
说成现实中的无进展。

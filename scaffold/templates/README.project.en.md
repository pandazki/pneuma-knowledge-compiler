## Build and inspect

1. Put your model credential in `.env` and your inputs in `my-data/` (or the external directory
   chosen during generation).
2. Read `engine/compile/contract.md`. {{CONTRACT_HINT}} Owner details in
   `engine/persona/profile.yaml` are optional; unknown facts stay blank.
3. Run the ordinary build, then check the library against its sources:

```bash
./start.sh                                  # validate inputs → start stack → ingest/compile per file
./app.py glance
./app.py ask 'A question you actually need answered' --sources
./app.py status
```

Build success means imported material and queue processing passed. It does not prove that
claims are correct, overviews are faithful, or useful facts were all retained. `--sources`
fetches the answer's exact cited L0 spans, including citations reached through compiled claims.
Check whether those passages really support the answer. Answer/evidence degradation is shown
explicitly. Private receipts in `data/run-reports/` retain input hashes, source IDs, engine
hashes, job history and answer details; compile-model tokens are only part of total cost.

## Material formats

The importer validates the entire top-level inventory before writing, and processes `.json`
and `.md` files in filename order (`README.md` is ignored). Use ordered filenames for a
chronological replay; it does not guess a new order from the content.

For structured exports, use the framework's `docs/reference/source-contracts.md`: one JSON
contract per file. Identity, message time, threads, metadata and media stay in their native
fields. A bundle may expand into several natural source units. Do not use a fabricated precise
timestamp or provider identity to force an export into a contract.

Markdown notes may carry any JSON-compatible frontmatter, which is retained as source metadata:

```markdown
---
title: Release decision
date: 2026-01-10
author: Product team
---
The team deferred the release until the accessibility review is complete.
```

A simple transcript may add `type: conversation` and use `Speaker: text` lines. Indent
continuation lines, including internal blank lines. Unattributed preamble and empty turns
are rejected. This limited grammar cannot represent arbitrary participant names or threads;
use a source contract for those. A date without a time remains a date, not an invented noon.

## Commands and operating boundaries

| Command | Purpose |
|---|---|
| `./app.py build [dir]` | Same normal build as `start.sh` |
| `./app.py ingest [dir]` | Import only; queues indexing and compilation |
| `./app.py compile` | Drain the normal queue; one additional attempt at unresolved compile work |
| `./app.py ask '…' --sources` | Structured fast answer and exact cited passages |
| `./app.py ask '…' --deep` | Agentic search/read loop; more model calls may be needed |
| `./app.py ask '…' --as-of 2026-01-10T12:00:00Z` | Explicit historical question time; omitted means now |
| `./app.py evolve step` | Create a structural proposal and keep it for review |
| `./app.py evolve show/adopt/drop TASK_ID` | Inspect or dispose of a proposal |
| `./app.py up`, `init`, `glance`, `status`, `down` | Stack, detected locale and library inspection |
| `./app.py restore` | Restore a shipped `prebuilt/` demonstration, when present |

Do not run CLI queue drains alongside the console worker. Retries retain failures; repeated
`compile` invocations can add attempts and must be counted in comparisons. `evolve step
--policy adopt-clean` explicitly opts into automatic adoption after mechanical checks; those
checks do not replace review of the proposed meaning.

For an interrupted CLI job, stop all workers using this stack, then run `./app.py compile
--recover`. Recovery requeues claimed jobs across this stack; normal builds never reclaim
a possibly live worker's job.

```bash
docker compose --profile console up -d --wait
# Browser UI: http://127.0.0.1:<PNEUMA_APP_WEB_PORT from .env>
```

## Change the library deliberately

`engine/` is its own Git repository: strategy, compile contract, optional owner profile and
prompt overlays. Start at `engine/README.md`. `.env` holds credentials and local ports;
`my-data/` holds inputs; `data/` holds private runtime state. Keep all three outside version
control. Environment overrides are for one-run diagnosis; durable strategy belongs in `engine/`.

A contract edit governs future compiles. Re-importing identical material normally deduplicates
it; a derived rebuild restores indexes and does not recompile canonical knowledge. Compare a
new contract in a fresh project while preserving the original. Do not routinely delete the
library to iterate. Explicit `down --volumes` deletes middleware data.

Generated machinery (`app.py`, `start.sh`, `server.py`, `worker.py`, `docker-compose.yml`) comes
from framework templates. Improve those templates rather than hiding strategy in copied code;
when replacing machinery, preserve this project's engine and data.

Framework: `{{FRAMEWORK_REPO}}`. Read `scaffold/AGENT-GUIDE.md` for the validation loop,
`docs/guides/compile-contract.md` for contract design and `docs/architecture.md` for internals.

# Compile-contract set

The ten contracts were derived only from the dataset structure and the first session of each
conversation, as permitted before FREEZE#1. They share a personal-history filing model but
name the two central participants and the initial directions observed in that one-session
window. Those directions are examples, never a closed subject list.

The shared engine sample uses caption-mode media because the markdown adapter preserves URLs,
captions, and image-search queries as labelled text but does not deliver remote image bytes as
native media. `people,time` are enabled: `time` has reliable session dates; `people` adds person
page structure and lookup, though markdown input has no account-level identities. `attention`
is omitted because evaluation asks are silent by protocol.

The answer style and the Phase-B evidence-strategy override are intentionally not fixed by the
sample defaults; those decisions belong to the post-FREEZE#1 exam phase. Candidate/final caps,
semantic chunking, component routing, and answer reasoning effort are already fixed because
they determine the available retrieval surface.

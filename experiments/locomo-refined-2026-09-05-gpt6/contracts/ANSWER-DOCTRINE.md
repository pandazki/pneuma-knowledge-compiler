# 答题 doctrine（考纲阶段）

适用全部问题，不按具体问题、话题或类别分流。只使用框架现有风格、证据、格式及推理旋钮。

- `fast`、`concise`：直接给出有据的紧凑答案，避免额外事实；完整性由证据和问题决定。
- `all`、`structured`：候选池交给答案模型，在框架内先做证据审阅，再给结构化答案及引用。
- 候选 claims 80、windows 60、all_context_chars 120000、plan_queries 3；people/time 使用框架默认路由。
- 答案角色 Luna，`answer_reasoning_effort=high`。不改事实约束、不强迫猜测；真正无据时保留框架的弃答。
- CLI 无痕访客（silent），不给访问账本写评测痕迹；32 个只读调用同时在飞，两库轮转且库内并行。
- 后处理只移除机器引用和 HTML 标记；不做日历猜测、不按题目内容改答案。

判官对时间粒度、相对时间形式和集合额外项严格。这里选择框架 concise 风格承担这些约束，
不使用金标决定时间单位，不改写问题，也不注入针对具体考题的提示。

# 变更链字段试写第零遍

这不是数据模型，只是把今天没听懂的地方摊开。样例仍用角色甲、角色乙和编造短句；两处陈放原句只留在访谈摘录页，不放进运行样例。字段名随时可删，空白不能自动补成结论。

| 暂用格子 | 想留下什么 | 现在为什么不可靠 |
| --- | --- | --- |
| 来源片段 | 一段没有改写的句子 | 还没定义会议、消息、文档如何定位 |
| 发生时刻 | 句子出现的大致时间 | 时间精度和时区没有比较 |
| 关系占位 | 句子之后是否发生了别的动作 | 我仍把更正误读成反对，不能先写枚举 |
| 留下判断的人 | 谁改变了关系占位 | 谁拥有这个资格完全未答 |
| 备注 | 不确定处和不同意见 | 不能拿备注替代来源片段 |

> 失败的草稿句：“陈放不同意这项变化。”它把他的两次更正都压成对内容的反对，不能进入样例。暂时只保留“他指出页面把两种情况写成了一种”，但“两种情况”具体如何表示仍未解决。

- 第一轮只做纸面卡，不接旧材料，不邀请陈放再次确认。
- 不把吴岚、陈放或林舟预填进“留下判断的人”。
- 不设置默认答案；空格就是当前缺口。
- 明天若讨论范围，先问要验证哪一个关系，不先问整个项目还缺哪些页面。

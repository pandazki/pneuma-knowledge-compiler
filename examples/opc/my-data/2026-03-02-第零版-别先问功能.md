# 第零版：别先问功能

我还是想先做一张跨来源的自动周报：会议里一句、消息里半句、邮件里一句，最后排成一条好看的线。这个想法很顺手，也很可疑。明天找贾宁时不要问他“能不能做”，先让他拆掉它。

| 可能先找谁 | 他在争议里会带什么 | 我不能替他回答的事 |
| --- | --- | --- |
| 接客户的人 | 当时答应了什么、后来客户又说了什么 | 哪一句算确认 |
| 现场协调的人 | 临时改动、照片、催促 | 谁能把状态改掉 |
| 做预算的人 | 版本、金额、附件 | 没回话是不是默认同意 |

- [ ] 先问：最近一次找不到依据是什么时候。
- [ ] 再问：你翻的第一处是哪儿。
- [ ] 不问：如果我给你一个总览，你会不会开心。这个问题太容易得到礼貌答案。
- [ ] 给吴岚的开场只写“想请你看一个样子”，不要写“接入”或“导入”。我还没有资格碰任何真实项目。

下午把桌角堆了半个月的收据按月份夹好，才发现其中两张只是便利店小票。热水壶除垢时忘了设提醒，水凉了又重新烧。它们跟这页问题都没关系，只是今天确实被这些小事切走了四十多分钟。

访谈时不要把“记录”说成要替人记住一切。更实际的问法也许是：当你要解释一次改动时，手边已经有什么，缺的又是哪一截。可能缺的是附件，可能是说话的人，可能只是消息发出的先后。答案不该替我决定产品，只能决定我下一页该少画什么。吴岚如果愿意看样，也只是给我一个被质疑的机会，不是对任何接入的许可。

> [!warning] 明早先删词
> 
> 把“自动整理全部沟通”“完整项目视图”“无须打扰任何人”划掉。它们都像承诺，而我现在连一位一线使用者怎么称呼自己的麻烦都不知道。

如果对方追问样子里有什么，只展示我手写的三段虚构对话：一段提议换材料，一段询问价差，一段明确说先等等。每段故意留一个空白，让她指出最先想补的是人、时间、原文还是结果。不要用旧咨询截图，也不要把“愿意看”解释成愿意交材料。看样结束后只记她真正指出的麻烦；礼貌的“挺有意思”不计入结论。
